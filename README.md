## Инструкция по использованию
Строковые значения необходимо заключать в двойные кавычки.
Вокруг знака `=` обязательны пробелы.

# Управление таблицами

Запуск базы данных (через bash):

project

## Создание таблицы со столбцами типов int, str и bool:

create_table users name:str age:int active:bool

Столбец ID:int добавляется автоматически.

## Просмотр таблиц и их структуры:

list_tables

## Удаление таблицы:

drop_table users

## Дополнительные команды:

- help — справка.
- exit — выход.

## Информация о новых возможностях

- Ошибки операций перехватываются и выводятся в терминал без остановки работы программы.
- Теперь удаление таблиц и записей требует подтверждения: `y` — выполнить, любой другой ответ — отменить.
- Для команд `insert` и `select` выводится время выполнения.
- Результаты одинаковых запросов `select` кэшируются в памяти для оптимизации работы программы.
- Кэш очищается при завершении программы.
