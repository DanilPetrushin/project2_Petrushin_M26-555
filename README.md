# Описание проекта
Данный проект представляет собой программу направленную на управление собственной базой данных, расположенной на локальном ПК в формате json с возможностью добавлять, удалять и читать метаданные, а также добавлять, изменять, удалять и показывать записи (с условием и без). Подробная информация о командах после запуска программы осуществляется с помощью функции help. Выход из программы осуществляется посредством команды exit.

## Установка и запуск
Для работы необходимы Git и менеджер пакетов uv.
Проект использует Python версии 3.12 или новее.

1) Клонируйте репозиторий и перейдите в каталог проекта:
```bash
git clone https://github.com/DanilPetrushin/project2_Petrushin_M26-555.git
cd project2_Petrushin_M26-555
```

2) Установите проект и зависимости:
```bash
uv sync
```

3) Запустите базу данных:
```bash
uv run project
```

## Инструкция по использованию
Строковые значения необходимо заключать в двойные кавычки.
Вокруг знака `=` обязательны пробелы.

## Хранилище данных
Метаданные — db_meta.json
Записи — data/<имя_таблицы>.json.


## Работа с метаданными
### Создание таблицы со столбцами типов int, str и bool:

create_table users name:str age:int active:bool

Столбец ID:int добавляется автоматически.

### Просмотр таблиц и их структуры:

list_tables

### Удаление таблицы:

drop_table users

## Работа с записями

### Добавление записи  
ID генерируется автоматически

```text
insert into users values "Данил" 22 true
```

### Просмотр всех записей

```text
select from users
```

### Просмотр по условию

```text
select from users where age = 22
```

### Обновление записей

```text
update users set age = 23 where ID = 1
```

### Удаление записей

```text
delete from users where ID = 1
```

Все поля обязательны. Поддерживается одно условие
равенства в `where` и изменение одного поля в `set`.

### Дополнительные команды:

- help — справка.
- exit — выход.

### Информация о новых возможностях

- Ошибки операций перехватываются и выводятся в терминал без остановки работы программы.
- Теперь удаление таблиц и записей требует подтверждения: `y` — выполнить, любой другой ответ — отменить.
- Для команд `insert` и `select` выводится время выполнения.
- Результаты одинаковых запросов `select` кэшируются в памяти для оптимизации работы программы.
- Кэш очищается при завершении программы.
